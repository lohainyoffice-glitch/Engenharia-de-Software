Aplicativo Web para Análise de Vendas de Veículos
Objetivo

Desenvolver e publicar um aplicativo web interativo para explorar dados de anúncios de vendas de veículos, aplicando práticas de engenharia de software e análise de dados.

Principais etapas
Criação e gestão de ambiente virtual em Python
Organização do projeto com Git e GitHub
Tratamento e exploração dos dados com Pandas
Criação de visualizações interativas com Plotly Express
Desenvolvimento do aplicativo com Streamlit
Implantação em nuvem utilizando o Render
Funcionalidades

O aplicativo permite explorar informações como preço, quilometragem, ano de fabricação, modelo e condição dos veículos por meio de gráficos e filtros interativos.

Tecnologias utilizadas

Python, Pandas, Plotly Express, Streamlit, Git, GitHub e Render.

Resultado

Foi desenvolvido um aplicativo web funcional e acessível ao público, reunindo análise exploratória, visualizações interativas e práticas de implantação em nuvem.Dataset
O projeto utiliza um conjunto de dados de anúncios de vendas de carros contendo informações como:
- Modelo e marca dos veículos
- Ano de fabricação
- Quilometragem
- Preço
- Condição do veículo
- E outras características relevantes
